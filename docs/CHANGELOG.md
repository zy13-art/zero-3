# 更新记录

## 1.5.0

- 默认由独立全屏播放器切换为Codex主窗口内的临时视频层，保留--native/--preview诊断入口。
- 尽早挂入不透明遮罩，不再等待聊天主界面或document.complete；首帧后显像，接收/解码/播放分别有界，异常不重复播放。
- 保留同目录启动互斥和会话幂等；修复同renderer失败状态被重试误判成功的问题。
- 独立校验本机监听进程，不依赖外部壁纸项目存在；现有壁纸仍为可选集成。
- 公开配置清空个人路径；Node留空时查找既有Codex任务运行时、Program Files和PATH。
- 更新四段4K60启动影片，使用宽尺度保边亮度增强；8秒剪辑、原AAC包、钟声、三秒线稿和水波渐糊退场保留。
- 新增旧快捷方式修复与原件备份，避免保留官方分组标识；不自动接管官方原入口或应用内重启。
- 更新说明、兼容性、素材限制及验证摘要。8K90存档仍为1.4.0，FFV1验证母版不打包。

验证：Windows隔离启动测试、浏览器完整播放/跳过/资源清理、四片全帧及376个AAC包。新版真实官方客户端冷启动未由上述测试代替，仍待设备实测。

## 1.4.0

独立WPF全屏播放器先遮盖显示器、后台启动Codex；四段八秒随机动画、三秒荧光线稿、原画可见钟体轮廓、单次Zi-O钟声与水波拉远收尾。
